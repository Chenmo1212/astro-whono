第128天

英国跨年旅行至此，算是告一段落。

行程主要为: 都柏林(Dublin) => 曼切斯特(Manchester) => 伦敦(London) => 利物浦(Liverpool) => 曼切斯特 => 都柏林

整体而已，这次旅行体验中规中矩。有些想做的事情没做到，比如寄明信片回国，并没有闲余时间和机会去买邮票，也没有去牛津。但也有些意外收获，比如曼切斯特艺术馆，大英博物馆带来的震撼。旅游的初衷意为暂时逃离世界，也并未做到，仍在担忧和被一些事情困扰。

旅行并非一帆风顺，相反十分波折。由于人生地不熟，在曼城一下飞机便遇到了许多问题，手机网络，未在合适的地方打车，早起赶机的身心俱疲，初到伦敦打不到车，坐地铁无法买票等等都很难不让人感到疲惫。

这些事情的发生，无一不让我感到自责惭愧。因为同行人里有女生，毕竟按我的观念也应该好好照顾她们才是。而我无论是出行前亦或是出行中，一有时间就在补作业，关于出行攻略的事情是一点也没准备。虽有万般理由，但仍有些许自责之意了，所幸并未耽误任何事情。

(今天的内容是在回程的飞机上写的，感慨一下: 从起步到拉杆抬起只用了7秒，机长也太勇了吧！)

旅途中印象最深刻的应该是曼切斯特艺术馆，大英博物馆以及利物浦的诺丁汉的公园了。

曼切斯特艺术馆其实跟国内没差，但兴许是文化不同的缘故，当我将置身于那些艺术品以及画作中时，带给我的感触很难用言语形容。

大英博物馆，作为最“臭名昭著”的博物馆之一，里面的馆藏的确让人为之惊叹而又气愤。免门票，但里面很大，很难在短时间内逛完。时常得走走歇歇，兴许得专门花上一段时间才能将其好好欣赏一番，否则绝大部分都是在走马观花了。国内的藏品比较少，但对于英国曾经的殖民地，比如印度。藏品数量真的多到恐怖。这所谓的英国绅士背后，一直都是靠着曾经的侵略和杀戮而得来的成果，的确让人唏嘘不已。

诺丁汉的公园，不是什么很出名的地方，只是因为当时想去牛津，结果未能赶上车，由于时间关系不得不放弃行程，便随意逛了一下附近的公园。前两天的天气很是糟糕，以至于同行者对英国有着诸多抱怨。可谁曾想，第二天伦敦就来了个艳阳高照。早上去逛公园，天气好得让我感动到想哭，那一刻算是成功逃离世俗的瞬间。

其余的，便零零碎碎了，有打卡一些著名的景点，也有遇到不错的建筑，还碰见许多很有范儿的漂亮美女及帅哥。照片视频什么的，最近想必是没有时间整理了，等过段时间吧，等把作业补完，看是否还有心情。

----

回到公寓了。

刚在机场，朋友打算打车回去，但一直都没有打到车。在等待的时候已经有几个司机在车上招呼我们了，但我们都没去搭理他们。后来我看一直没打到车，司机再打招呼时，我便过去了。对方说了什么我没注意听，直接就说我要去哪，然后询问去我那个地方多少钱。对方说大概20-25欧左右。我跟他确认了一遍，说我如果坐你这个车，去我那个地方，要20-25欧是吗？他跟我说他已经有预定了。

我顿悟，他原来不是来让我们上他的车的，只是看到我们在大风晚上等了很久，便想来跟我们提点建议。我才反应过来，他刚开始说的内容是: Uber打车软件很贵，因为他们会额外收费的，让我们直接打这里的车。

好生惭愧。因为我以为像这种在机场等客的司机都是会高于app价格的，结果没曾想。而且人家还是好心给的建议，我却。。。
