第260天

下午跟巴西大叔一起去的学校，路上我俩唠嗑。我问他昨晚是不是带他约会的女生回公寓了，他说我怎么知道，我说我听到他说话了“see, this is xxx. see this is xxxx”. 然后我问，昨晚女生是不是在他房间睡的，他说是。

牛蛙，巴西大叔的魅力还是很大的。咱就是说，这边的文化即使是现在，也时常让我感慨。一时兴起看对眼了，就先睡一觉再开始做朋友，或者继续发展。但不管怎样，想必巴西大叔撩妹的时候肯定很能说一些让对方开心的话。

巴西大叔说对方是隔壁大学的career adviser的，刚好可以帮他瞅瞅明天华为的终面。牛蛙牛蛙。

晚上我收到了第一封面试邀请，孩子要哭了。已经回复他了，等明天应该可以确定面试时间。晚上瞅了一下这个公司，发现给我发邮件的人，是这个公司的CEO。应该只是因为这是一个初创公司，所以人很少。害，这样的公司大多是钱少活多，还对未来职业没什么发展。但作为第一份面试，还是记录一下，就当练练面试了。

明天还得去郊区看房，希望那印度小哥不是骗子。找房真的太累了，明天的房子离市中心只要公交半小时，然后还是双人间，都带独卫。附近也有超市，已经是性价比很高的了。而且房租每个月都只要750欧。希望不是骗子
